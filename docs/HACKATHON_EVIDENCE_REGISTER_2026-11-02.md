## Evidence integrity rules

Record exact timestamps, source refs, SHA, machine/browser/OS, test command, pass/fail/skip, and whether calls were real or mocked. Never paste credentials, full model inputs from private scripts, or raw provider traces into a public repository. GitHub Actions artifacts expire; archive only sanitized proof with hashes, and ensure that private records stay private. Never backdate commits or imply a stage is complete because a plan says it will be.
