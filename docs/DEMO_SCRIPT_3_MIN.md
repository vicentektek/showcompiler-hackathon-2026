## Capture checklist

- Record the exact Git commit and application version used.
- Capture at 1920×1080 where possible; enlarge text for judges.
- Use an original or licensed short script and audio.
- Hide API keys, browser profiles, private project names and cost-account details.
- Prefer one uninterrupted real interaction per major claim; clearly label edits.
- Do not imply hardware outputs or live provider results that are not shown.
- Add English captions; optionally produce a Spanish version.
- Keep demo narration factual and avoid unverified latency/accuracy claims.
