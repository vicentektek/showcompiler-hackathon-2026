# RUNQ runtime capability catalogue

This is a compact, source-backed catalogue for expert-assistant context building, not a feature roadmap or live-show certification. The machine-readable source is `src/core/runqCapabilities.mjs`; records expose bilingual summaries, access paths, status, prerequisites, prohibitions, source line evidence, representative tests, and retrieval keywords.

`retrieveCapabilities(prompt, limit = 5)` returns a deterministic array of compact context records (`id`, `state`, bilingual `description`, `accessPath`, `prerequisites`, `prohibitions`, and evidence references `{file,line}`). Source-line help (for example, “Help with L2”) selects the script-reference entry. An unmatched help/assistance prompt returns the single generic overview record; unrelated unmatched prompts return an empty array. A broad catalogue question without an explicit limit returns all nine records, bounded to 5,000 serialized bytes; explicit limits are honored (maximum 12). The exported `RUNQ_CAPABILITIES` retains complete evidence, tests, and keywords. Evidence is verified by `node --test test/runqCapabilities.test.mjs`.
