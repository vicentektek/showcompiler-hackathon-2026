# RUNQ — visual design references (private inputs)

The RUNQ interface was developed using an internal set of eight reference images identified as A–H. The archived reference bundle has been **removed from the current public source tree** because distribution rights for all of its contents are not confirmed.

This archive is **not** necessary to install, run, or test RUNQ. New work should use fresh screenshots of the running app or independently licensed reference material.

The historical references were used as design inputs, not as runtime assets or evidence of existing implemented features. Some old development docs may refer to the reference pack.

**Important:** Removing an archive from the latest branch does not remove it from earlier Git commits, tags, or other public branches. The owner should separately consider whether historical assets require remediation.

No runtime features changed in this documentation cleanup.
