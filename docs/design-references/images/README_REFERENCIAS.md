# RUNQ — Referencias visuales aprobadas

OCHO imágenes para el agente de diseño e implementación.

## Prioridad

A–E: MOCKUPS APROBADOS, fuente de verdad visual para cada pantalla.
F: MediaBay, referencia de densidad de biblioteca y forma de onda.
G: Density & Workspace, referencia de layout multipanel compacto.
H: Modern Operation, referencia de jerarquía visual y estados.

## Restricciones de producto

Reproducir A–E con máxima fidelidad, manteniendo controles reales y todas las funciones existentes. No duplicar motor de audio ni cola de cues. No simular medidores ni botones. Conservar el Autopiloto de ensayo y los controles críticos de Directo.

## Uso en repositorio

Sube este ZIP a `docs/design-references/RUNQ_referencias_visuales_A-H.zip`. El agente debe descomprimirlo en una carpeta temporal y abrir las ocho imágenes antes de editar. Alternativamente extraerlas a `docs/design-references/` y subir los PNG individualmente.
