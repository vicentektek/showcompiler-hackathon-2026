## Critical distinction

Public GitHub visibility is **not** an open-source license. Without a repository license, third parties generally do not receive a broad permission to reproduce, modify or distribute the code. However, GitHub's platform terms still allow certain platform-native viewing/forking activities; this is not a guarantee that public code cannot be copied. Separate hackathon submission agreements may grant organizers rights even if the repository remains all-rights-reserved.

Secondary summaries describe a broad, non-exclusive, worldwide, perpetual, royalty-free license granted to organizers over submissions. **Verify the exact signed Event Waiver / Official Rules** before making definitive legal claims.
